# Чат-сервер на TCP сокетах с кастомным протоколом

Формат сообщения строится по принципу COMMAND + LENGTH + DATA. 
Заголовок всегда занимает ровно 8 байт:
1. `COMMAND` (4 байта) — текстовое название команды в кодировке UTF-8, дополненное пробелами справа до 4 символов (например, `JOIN`, `TEXT`).
2. `LENGTH` (4 байта) — длина полезной нагрузки (payload) в виде 4-байтового беззнакового целого числа в сетевом порядке байт (Big-Endian, формат `!I`).

Поддерживаемые команды:
* `JOIN <username>` — регистрация клиента на сервере.
* `TEXT <message>` — рассылка текстового сообщения всем участникам (broadcast).
* `LIST` — запрос списка активных пользователей.
* `QUIT` — штатное отключение клиента.
* `ERROR` — ответ сервера при неизвестной команде или ошибке.
