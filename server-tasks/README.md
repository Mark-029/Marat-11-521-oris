# Сервер задач

## 1. Запуск
Сервер: `python server.py` (слушает порт 5555)

Клиент: `python client.py`

## 2. Команды
* `/add <текст>` — добавить задачу
* `/list` — показать все задачи
* `/done <номер>` — отметить задачу выполненной
* `/delete <номер>` — удалить задачу
* `/quit` — закрыть клиент

## 3. Многопоточность
Используется модуль `threading`.
Сервер в главном цикле ждет подключения (`server.accept()`). При подключении нового клиента немедленно создается отдельный поток `threading.Thread(target=handle_client)` для его обслуживания. Главный поток при этом возвращается к ожиданию новых клиентов.

На клиенте также работает два потока: один ждет ввода пользователя в консоль, второй параллельно слушает сообщения от сервера.

## 4. Синхронизация
На сервере используется объект блокировки `tasks_lock = threading.Lock()` для защиты общего словаря `tasks`. Блок `with tasks_lock:` применяется при любом обращении к задачам (чтение, добавление, изменение, удаление). Это исключает «состояние гонки» (race condition) — например, чтобы два клиента при одновременном вызове `/add` не получили одинаковый ID и не перезаписали задачи друг друга.
