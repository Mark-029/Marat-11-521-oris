# PyQt6 - Task Manager

Десктопное приложение для управления задачами, написанное на Python с использованием библиотеки PyQt6. 

## Запуск приложения

Для работы приложения требуется установленная библиотека PyQt6:
```bash
pip install PyQt6
```
Запуск осуществляется стандартной командой:
```bash
python main.py
```

## Базовый функционал

1. Введите короткое название задачи в поле Task.
2. Добавьте подробности в поле Description.
3. Выберите уровень приоритета (Low, Medium, High).
4. Отметьте дополнительные опции (Important, Send notification).
5. Нажмите кнопку Create task, чтобы сохранить задачу.

## Дополнительные возможности

1. Интерактивный список: Все задачи сохраняются во внутренний список Python и отображаются в удобном текстовом поле прямо внутри окна программы.
2. Строка статуса: В левой верхней части окна отображается текущий статус приложения (`Status: Ready`, `Status: Task created` или `Status: Last task deleted`), информирующий пользователя об успешности действий.
3. Счетчик задач: В правой верхней части окна динамически обновляется счетчик (`Created tasks: X`), показывающий общее количество текущих задач.
4. Кнопка Clear: Быстро очищает все поля ввода и сбрасывает настройки по умолчанию, позволяя легко начать ввод новой задачи.
5. Кнопка Delete last task: Позволяет отменить последнее действие — удаляет последнюю созданную задачу из списка, обновляя интерфейс и счетчик.
