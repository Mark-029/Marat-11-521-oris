# Каталог отзывов на заведения

## Функционал

**Базовая часть:**
* Отображение списка всех отзывов на главной странице.
* Динамические маршруты для просмотра подробной информации о каждом отзыве.
* Добавление новых записей через HTML-форму.

**Часть 1. Редактирование объектов:**
* Реализовано изменение существующих записей.
* Данные проверяются на сервере (отсутствие пустых полей, оценка строго от 1 до 5).
* При ошибках валидации форма не сбрасывается, а возвращается с предупреждениями и ранее введёнными значениями.

**Часть 2. Дополнительная функциональность:**
* **2. Фильтрация.** На главной странице добавлен фильтр отзывов по оценке (реализовано через `request.args` и метод GET).
* **4. Удаление.** На странице подробностей добавлена кнопка для удаления отзыва (реализовано через форму и метод POST).
* **7. Страница статистики.** Создан отдельный маршрут `/stats`, выводящий общее количество отзывов, средний балл и количество отзывов с оценкой «5»[cite: 7].
